## Основной функционал

1. **Класс Product**  
Представляет товар в магазине с функционалом:
- Хранение атрибутов:
  - Название (name)
  - Описание (description)
  - Цена (price) - приватное свойство с валидацией
  - Количество на складе (quantity)
- Автоматическая проверка данных при создании
- Подтверждение понижения цены
- Класс-метод для создания товара из словаря с обработкой дубликатов
- Возможность складывать продукты по их общей стоимости

Дополнительные возможности:
- Реализация миксина ReprMixin для удобного вывода информации о создании объекта
- Полная поддержка абстрактного класса BaseProduct
- Валидация данных при изменении цены через property setter
- Поддержка сложения товаров одного типа через __add__


  1.1 ***Подкласс Smartphone***  
Наследует от Product и добавляет специфичные атрибуты:
- Производительность (efficiency) — числовой показатель (например, 95.5)
- Модель (model) — название модели (например, "Galaxy S23")
- Объём памяти (memory) — встроенная память в GB (например, 256)
- Цвет (color) — цвет устройства  
  1.2 ***Подкласс LawnGrass***  
Наследует от Product и добавляет атрибуты для газонной травы:  
- Страна-производитель (country) — например, "Россия"
- Срок прорастания (germination_period) — например, "14 дней"
- Цвет (color) — цвет травы

2. **Класс Category**  
Представляет категорию товаров с функционалом:
- Хранение атрибутов:
  - Название категории (name)
  - Описание категории (description)
  - Список товаров (products) - приватное свойство
- Автоматический подсчет:
  - Количества категорий (category_count)
  - Количества уникальных товаров (product_count)
- Методы:
  - Добавление товара (add_product) с проверкой типа через isinstance()
  - Геттер для форматированного вывода информации о товарах

Дополнительные возможности:
- Наследование от абстрактного класса BaseItem
- Реализация итерации через CategoryIterator
- Свойство total_cost для расчета общей стоимости товаров в категории
- Строковое представление с информацией о количестве товаров

3. **Класс Order**
- Представляет заказ на конкретный товар
- Наследует от BaseItem
- Включает валидацию количества товара (должно быть > 0)
- Свойство total_cost для расчета стоимости заказа
- Реализация __repr__ для отладочного вывода

4. **Абстрактные классы**
- BaseItem: базовый класс для элементов, содержащих товары (категории, заказы)
  - Абстрактное свойство total_cost
  - Свойство items_count для подсчета элементов
  - Общий интерфейс для работы с коллекциями товаров
- BaseProduct: базовый класс для всех продуктов
  - Определяет обязательный интерфейс для продуктов
  - Включает абстрактные методы и свойства

5. **Класс CategoryIterator**:  
Добавляет итерацию по категориям для класса Category
- Реализует протокол итератора Python
- Позволяет итерироваться по товарам категории
- Поддерживает большие коллекции товаров

6. **Миксины**
- ReprMixin: добавляет функциональность для отладочного вывода
  - Автоматический вывод информации при создании объекта
  - Форматированное строковое представление через __repr__

7. **Наследники Product**
- Smartphone и LawnGrass полностью реализуют интерфейс Product
- Добавляют специфичные для каждого типа товаров атрибуты
- Переопределяют строковое представление для вывода дополнительной информации

8. **Импорт данных**:  
Функционал загрузки данных:
- Загрузка категорий и товаров из JSON файла
- Обработка ошибок:
  - Отсутствие файла
  - Некорректный JSON
  - Отсутствующие поля
- Установка значений по умолчанию для отсутствующих полей
- Обработка неверных типов данных

9. **Обработка ошибок**  
Добавлен новый функционал:
- Класс ZeroQuantityError для обработки попыток добавления товаров с нулевым количеством
- Расширенная валидация данных в методах:
  - Проверка типа добавляемых товаров в Category
  - Проверка количества товаров при создании Order
  - Проверка цены и количества при создании Product
- Улучшена обработка ошибок в JSON импортере:
  - Более детальные сообщения об ошибках
  - Установка значений по умолчанию для отсутствующих полей
  - Пропуск невалидных товаров вместо остановки процесса


## Пример использования

```python
# Загрузка данных из JSON
categories = load_data_from_json("data/products.json")
for category in categories:
    print(category)
    for product in category:
        print(f"  - {product}")

# Создание заказа
phone = Product("Смартфон", "Android 13", 499.99, 10)
order = Order(phone, 2)
print(f"Стоимость заказа: {order.total_cost} руб.")          
        
# Создание товара
tv = Product("Телевизор", "4K OLED", 899.99, 5)
phone = Product("Смартфон", "Android 13", 499.99, 10)

# Создание категории
electronics = Category("Электроника", "Техника для дома", [tv, phone])

# Использование миксина
product = Product("Ноутбук", "16GB RAM", 999.99, 5)
# В консоль будет выведена информация о создании объекта

# Работа с абстрактными классами
def print_total_cost(item: BaseItem):
    print(f"Общая стоимость: {item.total_cost}")
    
# Итерация по категории
for product in category:
    print(product)
    
# Использование наследников Product
grass = LawnGrass("Трава", "Зелёная", 10.99, 100, "Россия", "14 дней", "зелёный")
smartphone = Smartphone("Galaxy", "Новый", 799.99, 10, 95.5, "S23", 256, "чёрный")
print(grass)
print(smartphone)

# Обработка ошибок
try:
    empty_product = Product("Пустой", "Тест", 10.0, 0)
except ZeroQuantityError as e:
    print(f"Ошибка: {e}")

# Работа с нулевыми количествами
try:
    order = Order(product, 0)
except ZeroQuantityError:
    print("Нельзя создать заказ с нулевым количеством")

# Вывод информации
print(f"Общая стоимость: {tv + phone} руб.")
```
